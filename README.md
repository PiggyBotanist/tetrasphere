# Tetrasphere

Tetrasphere is a model that maps $k$-mer composition into an embedding space
where distance approximates phylogenetic distance, and remains stable as sequences fragment. 

## Setup
```
# Install a new environment if necessary
pip install -r requirements.txt

# Export current repository as path
export TETRASPHERE_DATA_ROOT=/path/to/data
export TETRASPHERE_RESULT_ROOT=/path/to/results
```
